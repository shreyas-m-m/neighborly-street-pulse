# Neighborly Street Pulse

Create the initial frontend for a 24-hour college hackathon project named DataPulse — Civic Incident Intelligence Engine. Build a clean, responsive React + TypeScript website using Tailwind and shadcn/ui, React Router, and Lucide icons. For this first step, implement the overall app shell/navigation and a polished landing page, plus route placeholders for /report, /dashboard, and /incidents/:id. Visual style: deep navy, teal/cyan accents, light neutral surfaces, clear severity colors, accessible contrast, mobile-responsive layout. Landing page should explain civic incident reporting and prioritisation for overflowing garbage bins, damaged roads, water leaks, and broken streetlights, with clear CTA buttons to Report an Issue and View Dashboard. Use realistic mock data only if needed, clearly label it as demo data. Do not add a backend, database, API keys, or claim AI functionality. Keep the code modular and easy for a beginner to understand. Ensure navigation works and the project builds without errors. After implementing, summarize the files and next steps briefly.
